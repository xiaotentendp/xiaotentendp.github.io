核心项目

三个项目共同构成一个 Agent 自进化框架的三个承重模块。跑得稳、记得住、长不歪。

框架关系：项目一保障主体在执行侧的安全与状态可回滚；项目二保障探索所得经验在写入记忆时可信、在衰减时抗噪；项目三定义“主体稳定运行—隔离实例探索—审核后合入”的完整自进化流程。
Agent 零信任隔离与状态恢复系统 PoC 已验证

面向物理执行侧，将不可信数据与可信指令在文件系统层强制分离；以动作对象对交集作为确定性熔断判据，不依赖模型自我判断；快照回滚保证越权提案或上下文污染后系统可回到最后一个有效状态。

Agent 可信经验写入与抗噪衰减架构 PoC 已验证

污点追踪与三重门控：硬污点拦截、软污点降级为候选、干净执行才进主经验。中层仅存指针与摘要，底层日志链式哈希且仅追加，哈希双份存放，中层篡改可被底层锚点发现。失败解耦为自身不安全、任务不匹配与执行失败三类，环境性失败不降权。
